Software

Software

Open-source tools for literature review, text analysis and document forensics. The Stata modules are distributed through the Statistical Software Components (SSC) archive at Boston College.

Stata modules

  • litdiscover

    Stata 19 with Python

    Theory-aware literature review, analysis and discovery. Combines latent Dirichlet allocation topic modelling of abstracts with researcher-coded fields (theory, variables, context, method, year) to produce cross-tabulations, TCCM and ADO framework outputs, network measures and interactive figures for systematic reviews.

    ssc install litdiscover
    GitHub RePEc / SSC entry DOI

    How to cite

    • Davcik, N. S. (2026). LITDISCOVER: Stata module for theory-aware literature review, analysis, and discovery (Statistical Software Components S459718) [Computer software]. Boston College Department of Economics. https://ideas.repec.org/c/boc/bocode/s459718.html

  • littext

    Stata 19 with Python

    Automated construct discovery and relationship inference from academic text.

    ssc install littext
    GitHub RePEc / SSC entry DOI

    How to cite

    • Davcik, N. S. (2026). LITTEXT: Stata module to automate construct discovery and relationship inference from an academic text (Statistical Software Components S459756) [Computer software]. Boston College Department of Economics. https://ideas.repec.org/c/boc/bocode/s459756.html

  • litnetwork

    Stata 19 with Python In development

    Network analysis for literature reviews.

Research tools

  • transcriber

    Python

    Speaker-labelled transcription of a single audio file. Uses OpenAI Whisper for transcription, Resemblyzer voice embeddings and agglomerative clustering to attribute each segment to a speaker. MIT licence.

    GitHub

  • HTD Analyzer

    Windows · C# and Python

    Identifies and reveals concealed text in PDF, Word and Excel documents, using heuristics such as micro-fonts, near-white text and hidden-text attributes.

    Zenodo GitHub

  • DesktopSearchApp

    Windows · C#

    Indexes and searches local documents quickly, reliably and transparently.

    DOI

  • LLM-text-detection

    Python

    Code for text analysis and the detection of LLM prompting.

    GitHub

  • Hidden-text

    Python

    Research code for identifying hidden text in Word and PDF documents.

    GitHub
